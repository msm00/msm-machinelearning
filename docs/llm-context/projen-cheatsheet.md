## PRAVIDLO #1 – nikdy neupravuj generované soubory ručně
Soubory s komentářem `# ~~ Generated by projen` (pyproject.toml, tasks.json atd.)
se přepisují při každém `npx projen`. Změny patří do `.projenrc.py`.

## Workflow
```
edituj .projenrc.py  →  npx projen  →  generované soubory se aktualizují
```

## Minimální .projenrc.py
```python
from projen.python import PythonProject

project = PythonProject(
    author_email="email@example.com",
    author_name="Jméno",
    module_name="my_module",        # název Python balíčku (podtržítka)
    name="my-project",              # název projektu (pomlčky OK)
    version="0.1.0",
    deps=["requests@^2.28"],        # runtime závislosti
    dev_deps=["pytest@^7.4"],       # dev závislosti
)
project.synth()
```

## Dependency management
```python
# V options při vytváření projektu:
project = PythonProject(
    ...,
    deps=["balíček@verze", "requests@2.28.2"],
    dev_deps=["pytest@7.4.3"],
)

# Dodatečně (po vytvoření projektu):
project.add_dependency("numpy@^1.24")
project.add_dev_dependency("black@^23.0")

# Formát: <modul>@<semver>  např. "requests@^2.28" nebo "pandas@1.5.3"
```

## Výběr dependency manageru (vzájemně výlučné)
```python
# Poetry (venv + lock + publish) – tento projekt používá Poetry
PythonProject(..., poetry=True, pip=False, venv=False, setuptools=False)

# Pip (requirements.txt) – výchozí
PythonProject(..., pip=True, venv=True)

# uv (moderní, rychlý)
PythonProject(..., uv=True, pip=False, venv=False)
```

## Tasks
```python
# Přidat task
project.add_task("lint", exec="flake8 .")
project.add_task("format", exec="black .")

# Odebrat task
project.remove_task("build")

# Spustit task (v terminálu):
npx projen lint
npx projen test
npx projen build
```

## pyproject.toml overrides (PEP 621 / custom sekce)
```python
from projen.python import PyprojectTomlFile

# Najdi PyprojectTomlFile komponent
pyproject = next(
    c for c in project.components
    if isinstance(c, PyprojectTomlFile)
)

# Přidat/přepsat hodnotu (dot notation pro vnořené klíče)
pyproject.add_override("project.name", "my-project")
pyproject.add_override("project.requires-python", ">=3.13")
pyproject.add_override("project.dynamic", ["dependencies"])
pyproject.add_override("project.authors", [{"name": "X", "email": "x@y.z"}])

# Smazat klíč
pyproject.add_deletion_override("tool.poetry.name")
pyproject.add_deletion_override("tool.poetry.version")

# Přidat do pole
pyproject.add_to_array("project.classifiers", "Programming Language :: Python :: 3")
```

## Pytest konfigurace

PythonProject(

## Escape hatches – přímá editace generovaných souborů
```python
pyproject.add_override("tool.mypy.strict", True)        # přidat/přepsat
pyproject.add_deletion_override("tool.poetry.name")     # smazat klíč
pyproject.add_to_array("project.classifiers", "...")     # přidat do pole
```

## SampleFile – soubory editovatelné uživatelem
```python
from projen import SampleFile
# Vygeneruje soubor jen pokud neexistuje (bezpečné pro editaci)
SampleFile(project, "config/settings.py", options={"contents": "DEBUG = True\n"})
```

## Task – pokročilé (viz 06-tasks-advanced.md)
```python
task = project.add_task("ci")
task.exec("npx projen test")
task.exec("npx projen lint")
task.env("CI", "true")
task.add_condition("test -n \"$CI\"")   # přeskočit pokud CI není nastaveno
task.spawn(project.tasks.find("build")) # spustit podtask
```

## Klíčové PythonProjectOptions (nejdůležitější)
| Parametr | Typ | Výchozí | Popis |
|----------|-----|---------|-------|
| `name` | str | povinné | Název projektu |
| `module_name` | str | povinné | Python modul (podtržítka) |
| `author_name` | str | povinné | Jméno autora |
| `author_email` | str | povinné | Email autora |
| `version` | str | "0.1.0" | Verze balíčku |
| `deps` | list[str] | [] | Runtime závislosti |
| `dev_deps` | list[str] | [] | Dev závislosti |
| `poetry` | bool | False | Použít Poetry |
| `pip` | bool | True* | Použít pip (*False pokud poetry=True) |
| `venv` | bool | True* | Použít venv (*False pokud poetry=True) |
| `uv` | bool | False | Použít uv |
| `pytest` | bool | True | Zapnout pytest |
| `sample` | bool | True | Generovat ukázkový kód |
| `description` | str | None | Popis balíčku |
| `license` | str | None | SPDX identifikátor licence |
