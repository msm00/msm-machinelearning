# Projen – základní koncepty

> Zdroj: https://projen.io/docs/introduction + https://projen.io/docs/api/projen
> Chunk 0/5 – jak projen funguje (lifecycle, components, synthesis)

## Co je projen?

Projen je nástroj pro správu konfigurace projektů přes kód.
Místo ruční editace `pyproject.toml`, `.github/workflows/*.yml` a dalších souborů
definuješ projekt v `.projenrc.py` a projen vygeneruje vše ostatní.

```
.projenrc.py  →  npx projen  →  pyproject.toml, tasks.json, .gitignore, ...
```

**Klíčová vlastnost:** Generované soubory jsou označeny komentářem
`# ~~ Generated by projen` a při každém `npx projen` se přepisují.
Ruční změny se ztratí!

---

## Životní cyklus syntézy (Synthesis Lifecycle)

Při každém `npx projen` (nebo `project.synth()`) proběhnou tyto fáze v pořadí:

```
1. preSynthesize()    – příprava, výpočty, validace
2. synth()            – vygenerování obsahu souborů do paměti
3. DELETE             – smazání starých generovaných souborů
4. WRITE              – zápis nových souborů na disk
5. postSynthesize()   – post-processing (instalace deps, spuštění nástrojů)
```

V `.projenrc.py` se vše spouští voláním `project.synth()` na konci souboru.

## Construct Tree (strom komponent)

Projen je postaven na AWS CDK Constructs.
Každý projekt je strom vzájemně vnořených "konstruktů":

```
PythonProject
├── Poetry              (deps_manager)
├── Projenrc            (projenrc.py management)
├── PyprojectTomlFile   (pyproject.toml)
├── Pytest              (testing)
├── GitAttributesFile   (.gitattributes)
└── IgnoreFile          (.gitignore)
```

Přístup ke komponentám:
```python
# Všechny komponenty
project.components

# Najít konkrétní komponentu
from projen.python import PyprojectTomlFile
pyproject = next(c for c in project.components if isinstance(c, PyprojectTomlFile))
```

## Komponenty (Components)

Komponenty jsou znovupoužitelné stavební bloky. Každá komponenta:
- Přijímá `project` jako první argument (scope)
- Implementuje lifecycle metody (`pre_synthesize`, `synthesize`, `post_synthesize`)
- Generuje jeden nebo více souborů

### Lifecycle hooks komponent

```python
# Komponenta implementuje tyto metody (volány automaticky projenem):
def pre_synthesize(self):  # voláno před syntézou – příprava
    pass

def synthesize(self):      # hlavní syntéza – generování souborů
    pass

def post_synthesize(self): # po syntéze – instalace, post-processing
    pass
```

## Soubory (Files)

### FileBase – základ všech generovaných souborů

Každý generovaný soubor dědí z `FileBase`:

| Property | Typ | Popis |
|----------|-----|-------|
| `path` | `str` | Relativní cesta souboru v projektu |
| `absolute_path` | `str` | Absolutní cesta na disku |
| `readonly` | `bool` | Zda je soubor read-only (výchozí True pro generované) |
| `executable` | `bool` | Zda má být soubor spustitelný |
| `marker` | `str\|None` | Projen marker komentář (None při eject) |
| `committed` | `bool` | Zda se soubor commituje do gitu |

### SampleFile – soubory generované jen jednou

`SampleFile` generuje soubor pouze pokud ještě neexistuje.
Vhodné pro ukázkový kód, který uživatel může editovat.

```python
from projen import SampleFile

SampleFile(
    project,
    "msm_machinelearning/example.py",
    options={
        "contents": "# Example code\nprint('hello')\n"
    }
)

# Nebo ze zdrojového souboru:
SampleFile(
    project,
    "config/default.yaml",
    options={"source_path": "/abs/path/to/template.yaml"}
)
```

### JsonFile, YamlFile, TomlFile – strukturované soubory

Všechny podporují stejné escape hatches jako `PyprojectTomlFile`:
- `add_override(path, value)`
- `add_deletion_override(path)`
- `add_to_array(path, *values)`
- `patch(*patches)` (RFC 6902 JSON Patch)

---

## Escape Hatches – obejití projen API

Když projen API nestačí, použij escape hatches na přímo upravit generované soubory:

### 1. addOverride / add_override
```python
# Přidat/přepsat hodnotu (dot notation)
pyproject.add_override("tool.mypy.strict", True)
pyproject.add_override("tool.ruff.line-length", 120)
```

### 2. addDeletionOverride / add_deletion_override
```python
# Smazat klíč
pyproject.add_deletion_override("tool.poetry.name")
```

### 3. addToArray / add_to_array
```python
# Přidat do pole
pyproject.add_to_array("project.classifiers", "Programming Language :: Python :: 3")
```

### 4. patch (RFC 6902 JSON Patch)
```python
from projen import JsonPatch

pyproject.patch(JsonPatch.add("/tool/mypy/ignore_missing_imports", True))
pyproject.patch(JsonPatch.replace("/project/version", "0.2.0"))
pyproject.patch(JsonPatch.remove("/tool/poetry/name"))
```

## tryRemoveFile – odebrání souboru z projektu

```python
# Odebere soubor, pokud existuje
project.try_remove_file("README.md")
project.try_remove_file("setup.py")
```

## Nový projekt – bootstrap

```bash
# Vytvořit nový Python projekt s projen:
npx projen new python --module-name my_module --name my-project

# S Poetry:
npx projen new python --module-name my_module --name my-project --poetry

# Přegenerovat existující projekt:
npx projen
```

## Důležité soubory

| Soubor | Stav | Popis |
|--------|------|-------|
| `.projenrc.py` | **Editovat** | Definice projektu |
| `pyproject.toml` | Generovaný | Konfigurace Python balíčku |
| `poetry.lock` | Generovaný | Lockfile závislostí |
| `.projen/tasks.json` | Generovaný | Definice tasků |
| `.gitignore` | Generovaný | Git ignore vzory |
| `.gitattributes` | Generovaný | Git atributy |
| `tests/` | **Editovat** | Testy (generovány jen pokud neexistují) |
| `msm_machinelearning/` | **Editovat** | Zdrojový kód modulu |
