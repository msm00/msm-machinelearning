# Projen Python API – PyprojectTomlFile a overrides

> Zdroj: https://projen.io/docs/api/python
> Chunk 3/5 – PyprojectTomlFile, addOverride, PEP 621 konfigurace

## PyprojectTomlFile

Reprezentuje `pyproject.toml`. Získá se jako komponenta projektu.

```python
from projen.python import PyprojectTomlFile, PythonProject

project = PythonProject(...)

# Získání komponenty
pyproject = next(
    c for c in project.components
    if isinstance(c, PyprojectTomlFile)
)
```

## Metody PyprojectTomlFile

### add_override(path, value)

Přidá nebo přepíše hodnotu v generovaném souboru.
Tečková notace pro vnořené klíče.

```python
# Jednoduché hodnoty
pyproject.add_override("project.name", "my-project")
pyproject.add_override("project.version", "0.2.0")
pyproject.add_override("project.requires-python", ">=3.13,<4.0")
pyproject.add_override("project.description", "Popis projektu")
pyproject.add_override("project.readme", "README.md")

# Pole
pyproject.add_override("project.dynamic", ["dependencies"])

# Vnořené objekty (jako list dicts)
pyproject.add_override(
    "project.authors",
    [{"name": "Jméno", "email": "email@example.com"}]
)

# Booleany
pyproject.add_override("tool.poetry.package-mode", False)
```

### add_deletion_override(path)

Odstraní klíč z generovaného souboru. Zkratka pro `add_override(path, None)`.

```python
# Smazat Poetry metadata (při PEP 621 migration)
pyproject.add_deletion_override("tool.poetry.name")
pyproject.add_deletion_override("tool.poetry.version")
pyproject.add_deletion_override("tool.poetry.description")
pyproject.add_deletion_override("tool.poetry.readme")
pyproject.add_deletion_override("tool.poetry.authors")
```

### add_to_array(path, *values)

Přidá hodnoty do existujícího pole v souboru.

```python
pyproject.add_to_array(
    "project.classifiers",
    "Programming Language :: Python :: 3",
    "License :: OSI Approved :: MIT License",
)

pyproject.add_to_array("project.keywords", "machine-learning", "python")
```

### patch(*patches)

Aplikuje RFC 6902 JSON-patch operace.

```python
from projen import JsonPatch

# Přidat hodnotu
pyproject.patch(JsonPatch.add("/project/keywords/-", "new-keyword"))

# Nahradit hodnotu
pyproject.patch(JsonPatch.replace("/project/version", "0.2.0"))

# Smazat hodnotu
pyproject.patch(JsonPatch.remove("/tool/poetry/name"))
```

## Vzorová funkce pro PEP 621 overrides

Tento projekt (msm-machinelearning) používá tento vzor:

```python
def apply_pep621_overrides(pyproject: PyprojectTomlFile) -> None:
    """Přesune metadata z [tool.poetry] do [project] (PEP 621)."""
    # Smazat duplicitní Poetry metadata
    for key in [
        "tool.poetry.name",
        "tool.poetry.version",
        "tool.poetry.description",
        "tool.poetry.readme",
        "tool.poetry.authors",
    ]:
        pyproject.add_deletion_override(key)

    # Přidat standardní PEP 621 metadata
    pyproject.add_override("project.name", PROJECT_NAME)
    pyproject.add_override("project.version", PROJECT_VERSION)
    pyproject.add_override("project.description", PROJECT_DESCRIPTION)
    pyproject.add_override("project.readme", "README.md")
    pyproject.add_override("project.requires-python", PYTHON_RANGE)
    pyproject.add_override("project.dynamic", ["dependencies"])
    pyproject.add_override(
        "project.authors",
        [{"name": AUTHOR_NAME, "email": AUTHOR_EMAIL}],
    )
```

## Výsledná struktura pyproject.toml

```toml
# ~~ Generated by projen. To modify, edit .projenrc.py and run "npx projen".

[build-system]
requires = [ "poetry-core" ]
build-backend = "poetry.core.masonry.api"

[tool.poetry.dependencies]
beautifulsoup4 = "4.12.3"
python = ">=3.13,<4.0"

[tool.poetry.group.dev.dependencies]
projen = "0.99.58"
pytest = "7.4.3"

[project]
name = "my-project"
version = "0.1.0"
description = "Popis"
readme = "README.md"
requires-python = ">=3.13,<4.0"
dynamic = [ "dependencies" ]

  [[project.authors]]
  name = "Jméno"
  email = "email@example.com"
```

## Tečková notace – pravidla

| Vzor | Příklad |
|------|---------|
| Vnořené klíče | `"tool.poetry.name"` |
| Pole (index) | `"project.authors.0.name"` |
| Literální tečka v klíči | `"tool.my\\.key"` (escapovat `\\.`) |
| Přidat na konec pole | Použij `add_to_array()` místo `add_override()` |
